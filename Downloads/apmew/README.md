# APMEW — Planificación Financiera

Dashboard financiero para planificación de retiro. Conectado a Supabase.

## Cómo instalar y correr

### Requisitos previos
- Tener instalado **Node.js** (versión 18 o mayor) → [nodejs.org](https://nodejs.org)
- Tener instalado **Git** → [git-scm.com](https://git-scm.com)

### Pasos

1. **Clona el repositorio:**
```bash
git clone https://github.com/TU_USUARIO/apmew.git
cd apmew
```

2. **Instala las dependencias:**
```bash
npm install
```

3. **Corre el proyecto en tu máquina:**
```bash
npm run dev
```

4. **Abre en el navegador:**
Ve a `http://localhost:5173`

## Despliegue en Vercel (para tener URL pública)

1. Ve a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de GitHub
2. Click en "Import Project" y selecciona tu repositorio `apmew`
3. Vercel detecta automáticamente que es un proyecto Vite
4. Click en "Deploy"
5. Listo — te da una URL como `apmew.vercel.app`

## Stack
- React 18
